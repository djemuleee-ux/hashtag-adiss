# HASHTAG ADISS CLUB 22 — Final App v1

A deployable mobile-first PWA + Node/Express API for table bookings, song requests, celebration requests, events and a manager dashboard.

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.
5. Manager: `http://localhost:3000/admin`.

Demo manager login: `admin` / `hashtag22`.
Change this before production.
